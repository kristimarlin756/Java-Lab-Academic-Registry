Experiment 1: Exception Handling Using try and catch

Aim: To handle division by zero using try and catch.

Program

public class DivideDemo {
    public static void main(String[] args) {
        int a = 10;
        int b = 0;

        try {
            int result = a / b;
            System.out.println("Result: " + result);
        } catch (ArithmeticException e) {
            System.out.println("Cannot divide by zero");
        }

        System.out.println("Program continues");
    }
}

Program continues

Experiment 11: InputStream and OutputStream

Aim: To demonstrate reading and writing bytes using InputStream and OutputStream.

Program

import java.io.*;

public class ByteStreamDemo {
    public static void main(String[] args) throws IOException {

        byte data[] = {65, 66, 67, 68};

        InputStream in = new ByteArrayInputStream(data);
        OutputStream out = new ByteArrayOutputStream();

        int ch;

        while ((ch = in.read()) != -1) {
            out.write(ch);
        }

        System.out.println("Output: " + out.toString());

        in.close();
        out.close();
    }
}

Output

Output: ABCD

Experiment 15: Copy an Image Using Byte Streams

Aim: To copy an image using byte streams and handle FileNotFoundException and IOException.

Place an image named source.jpg in the same folder as the Java program.

Program

import java.io.*;

public class CopyImage {
    public static void main(String[] args) {
        FileInputStream fin = null;
        FileOutputStream fout = null;

        try {
            fin = new FileInputStream("source.jpg");
            fout = new FileOutputStream("copy.jpg");

            int ch;

            while ((ch = fin.read()) != -1) {
                fout.write(ch);
            }

            System.out.println("Image copied successfully");

        } catch (FileNotFoundException e) {
            System.out.println("Image file not found");
        } catch (IOException e) {
            System.out.println("I/O Error");
        } finally {
            try {
                if (fin != null) {
                    fin.close();
                }

                if (fout != null) {
                    fout.close();
                }
            } catch (IOException e) {
                System.out.println("Error closing file");
            }
        }
    }
}

Output

Image copied successfully

The output assumes source.jpg exists in the program's working folder.
