Week 9: Packages and Interfaces

Experiment 1: Creating and Using a User-Defined Package

Aim: To create a user-defined package and access its class from another Java program.

Student.java (inside mypackage folder)

package mypackage;

public class Student {
    int rollNo = 101;
    String name = "Kristi";

    public void display() {
        System.out.println("Roll Number: " + rollNo);
        System.out.println("Name: " + name);
    }
}

Main.java

import mypackage.Student;

public class Main {
    public static void main(String[] args) {
        Student s = new Student();
        s.display();
    }
}

Sample Output

Roll Number: 101
Name: Kristi

Experiment 3: Packages and Member Access

Aim: To demonstrate the accessibility of class members across packages using access modifiers.

AccessDemo.java (inside pack1 folder)

package pack1;

public class AccessDemo {
    public int a = 10;
    private int b = 20;
    protected int c = 30;
    int d = 40;

    public void display() {
        System.out.println("Public: " + a);
        System.out.println("Private: " + b);
        System.out.println("Protected: " + c);
        System.out.println("Default: " + d);
    }
}

SamePackage.java (inside pack1 folder)

package pack1;

public class SamePackage {
    public static void main(String[] args) {
        AccessDemo obj = new AccessDemo();

        System.out.println("Public: " + obj.a);
        System.out.println("Protected: " + obj.c);
        System.out.println("Default: " + obj.d);
    }
}

OtherPackage.java (inside pack2 folder)

package pack2;
import pack1.AccessDemo;

public class OtherPackage {
    public static void main(String[] args) {
        AccessDemo obj = new AccessDemo();

        System.out.println("Public: " + obj.a);
    }
}

Sample Output

Inside AccessDemo:
Public: 10
Private: 20
Protected: 30
Default: 40

Same package:
Public: 10
Protected: 30
Default: 40

Different package:
Public: 10

Note: Private members are accessible only inside their own class. Protected members are also accessible in subclasses in other packages.

Experiment 6: Defining and Implementing an Interface

Aim: To create an interface and implement its methods in a class.

Program

interface Shape {
    double area();
}

class Circle implements Shape {
    public double area() {
        return 3.14 * 5 * 5;
    }
}

class Rectangle implements Shape {
    public double area() {
        return 10 * 5;
    }
}

public class ShapeDemo {
    public static void main(String[] args) {
        Shape c = new Circle();
        Shape r = new Rectangle();

        System.out.println("Circle Area: " + c.area());
        System.out.println("Rectangle Area: " + r.area());
    }
}

Sample Output

Circle Area: 78.5
Rectangle Area: 50.0

Aim: To demonstrate polymorphism using an interface reference.

}

Experiment 12: Real-World Application Using Interfaces

Aim: To develop a Java application using interfaces.

Program

import java.util.Scanner;

interface Payment {
    void pay(double amount);
}

class CreditCardPayment implements Payment {
    public void pay(double amount) {
        System.out.println("Paid " + amount + " using Credit Card");
    }
}

class UPIPayment implements Payment {
    public void pay(double amount) {
        System.out.println("Paid " + amount + " using UPI");
    }
}

class NetBankingPayment implements Payment {
    public void pay(double amount) {
        System.out.println("Paid " + amount + " using Net Banking");
    }
}

public class PaymentDemo {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.println("1. Credit Card");
        System.out.println("2. UPI");
        System.out.println("3. Net Banking");

        System.out.print("Enter your choice: ");
        int choice = sc.nextInt();

        System.out.print("Enter amount: ");
        double amount = sc.nextDouble();

        Payment p;

        switch (choice) {
            case 1:
                p = new CreditCardPayment();
                break;
            case 2:
                p = new UPIPayment();
                break;
            case 3:
                p = new NetBankingPayment();
                break;
            default:
                System.out.println("Invalid choice");
                sc.close();
                return;
        }

        p.pay(amount);
        sc.close();
    }
}

Sample Output

1. Credit Card
2. UPI
3. Net Banking
Enter your choice: 2
Enter amount: 500
Paid 500.0 using UPI
