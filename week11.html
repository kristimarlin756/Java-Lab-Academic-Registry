Week 11: Character Streams and Multithreaded Programming

Experiment 1: Keyboard Input Using Reader and Writer

Aim: To read characters from the keyboard using Reader and display them using Writer.

Program

import java.io.*;

public class KeyboardDemo {
    public static void main(String[] args) throws IOException {
        Reader r = new InputStreamReader(System.in);
        Writer w = new OutputStreamWriter(System.out);

        System.out.print("Enter text: ");

        int ch;
        while ((ch = r.read()) != '\n' && ch != -1) {
            w.write(ch);
        }

        w.flush();
    }
}

Sample Output

Enter text: Hello Java
Hello Java
Experiment 2: Read a Text File Using FileReader

Aim: To read the contents of a text file using FileReader.

Create a file named input.txt containing: Welcome to Java.

Program

import java.io.*;

public class ReadFile {
    public static void main(String[] args) {
        try {
            FileReader fr = new FileReader("input.txt");

            int ch;
            while ((ch = fr.read()) != -1) {
                System.out.print((char) ch);
            }

            fr.close();
        } catch (IOException e) {
            System.out.println("File error");
        }
    }
}

Output

Welcome to Java

Experiment 4: Copy One Text File into Another

Aim: To copy the contents of one text file into another using FileReader and FileWriter.

Create input.txt containing: Java Programming.

Program

import java.io.*;

public class CopyTextFile {
    public static void main(String[] args) {
        try {
            FileReader fr = new FileReader("input.txt");
            FileWriter fw = new FileWriter("copy.txt");

            int ch;
            while ((ch = fr.read()) != -1) {
                fw.write(ch);
            }

            fr.close();
            fw.close();

            System.out.println("File copied successfully");
        } catch (IOException e) {
            System.out.println("File error");
        }
    }
}

Output

File copied successfully
Experiment 5: Count Characters, Words and Lines in a File

Aim: To count the number of characters, words and lines in a text file using character streams.

Create input.txt with the following two lines: Hello Java / Welcome Students

Program

import java.io.*;

public class FileCount {
    public static void main(String[] args) {
        int characters = 0;
        int words = 0;
        int lines = 0;

        try {
            BufferedReader br =
                new BufferedReader(new FileReader("input.txt"));

            String line;

            while ((line = br.readLine()) != null) {
                lines++;
                characters += line.length();

                String[] w = line.trim().split("\\s+");

                if (!line.trim().isEmpty()) {
                    words += w.length;
                }
            }

            br.close();

            System.out.println("Characters: " + characters);
            System.out.println("Words: " + words);
            System.out.println("Lines: " + lines);

        } catch (IOException e) {
            System.out.println("File error");
        }
    }
}

Output

Characters: 26
Words: 4
Lines: 2

Character count excludes newline characters.

Experiment 10: Use of isAlive() Method

Aim: To check whether a thread is running using the isAlive() method.

Program

class MyThread extends Thread {
    public void run() {
        System.out.println("Thread is running");
    }
}

public class IsAliveDemo {
    public static void main(String[] args) {
        MyThread t = new MyThread();

        System.out.println("Before start: " + t.isAlive());

        t.start();

        System.out.println("After start: " + t.isAlive());

        try {
            t.join();
        } catch (InterruptedException e) {
            System.out.println(e);
        }

        System.out.println("After completion: " + t.isAlive());
    }
}

Sample Output

Before start: false
Thread is running
After start: true
After completion: false

The thread may finish before the second isAlive() check on a very fast system. The sample output shows the usual result.

Program

class MyThread extends Thread {
    public void run() {

Experiment 12: Multiple Threads Using isAlive() and join()

Aim: To create multiple threads and control their execution using isAlive() and join().

Program

class MyThread extends Thread {
    public void run() {
        for (int i = 1; i <= 3; i++) {
            System.out.println(getName() + ": " + i);
        }
    }
}

public class ThreadControl {
    public static void main(String[] args) {
        MyThread t1 = new MyThread();
        MyThread t2 = new MyThread();

        t1.start();
        t2.start();

        System.out.println("Thread 1 Alive: " + t1.isAlive());
        System.out.println("Thread 2 Alive: " + t2.isAlive());

        try {
            t1.join();
            t2.join();
        } catch (InterruptedException e) {
            System.out.println(e);
        }

        System.out.println("Thread 1 Alive: " + t1.isAlive());
        System.out.println("Thread 2 Alive: " + t2.isAlive());

        System.out.println("Main thread completed");
    }
}

Sample Output

Thread 1 Alive: true
Thread 2 Alive: true
Thread-0: 1
Thread-0: 2
Thread-0: 3
Thread-1: 1
Thread-1: 2
Thread-1: 3
Thread 1 Alive: false
Thread 2 Alive: false
Main thread completed

The order of thread messages can vary because both threads execute concurrently.
