Experiment 1: String Constructors

Problem Statement: Write a Java program to demonstrate different ways of creating and initializing String objects using various String constructors.

Program 1: String Constructors

import java.util.Arrays;

class StringConstructors {
    public static void main(String[] args) {

        // String using string literal
        String s1 = "Java Programming";

        // String using new String()
        String s2 = new String("Object Oriented");

        // String from character array
        char[] chars = {'C', 'o', 'd', 'i', 'n', 'g'};
        String s3 = new String(chars);

        // String from byte array
        byte[] bytes = {72, 101, 108, 108, 111};
        String s4 = new String(bytes);

        // Display strings
        System.out.println("String using literal: " + s1);
        System.out.println("String using new String(): " + s2);
        System.out.println("String from character array: " + s3);
        System.out.println("String from byte array: " + s4);

        // Demonstrating difference between literal and new
        String s5 = "Java";
        String s6 = new String("Java");

        System.out.println("\nLiteral and new String comparison:");
        System.out.println("Using == : " + (s5 == s6));
        System.out.println("Using equals() : " + s5.equals(s6));
    }
}

Sample Output:

String using literal: Java Programming
String using new String(): Object Oriented
String from character array: Coding
String from byte array: Hello

Literal and new String comparison:
Using == : false
Using equals() : true

Experiment 2: StringBuffer Class

Problem Statement: Write a Java program to demonstrate the functionality of the StringBuffer class by performing various mutable string operations.

Program 2: StringBuffer Demo

class StringBufferDemo {
    public static void main(String[] args) {

        StringBuffer sb = new StringBuffer("Core Java");

        System.out.println("Initial String: " + sb);

        // Append
        sb.append(" Lab");
        System.out.println("After append: " + sb);

        // Insert
        sb.insert(5, "Advanced ");
        System.out.println("After insert: " + sb);

        // Replace
        sb.replace(0, 4, "Java");
        System.out.println("After replace: " + sb);

        // Delete
        sb.delete(5, 14);
        System.out.println("After delete: " + sb);

        // Reverse
        sb.reverse();
        System.out.println("After reverse: " + sb);

        // Length and capacity
        System.out.println("Length: " + sb.length());
        System.out.println("Capacity: " + sb.capacity());
    }
}

Experiment 3: StringTokenizer Class

Problem Statement: Write a Java program to tokenize a sentence using the StringTokenizer class and display each individual token.

Program 3: StringTokenizer Demo

import java.util.Scanner;
import java.util.StringTokenizer;

class StringTokenizerDemo {
    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        System.out.print("Enter a sentence: ");
        String sentence = sc.nextLine();

        StringTokenizer st = new StringTokenizer(sentence);

        System.out.println("\nTokens:");
        while (st.hasMoreTokens()) {
            System.out.println(st.nextToken());
        }

        System.out.println("Total number of tokens: " + st.countTokens());

        System.out.print("\nEnter a delimiter: ");
        String delimiter = sc.nextLine();

        StringTokenizer st2 = new StringTokenizer(sentence, delimiter);

        System.out.println("\nTokens using delimiter '" + delimiter + "':");

        int count = 0;
        while (st2.hasMoreTokens()) {
            System.out.println(st2.nextToken());
            count++;
        }

        System.out.println("Total tokens: " + count);

        sc.close();
    }
}

Sample Output:

Note: The original program calls countTokens() after the first loop has consumed all tokens, so it displays 0. The delimiter example uses a, which splits at each occurrence of that character.

Experiment 4: Basic Inheritance

Problem Statement: Write a Java program to demonstrate single inheritance by creating a superclass containing common properties and methods and a subclass that inherits and extends its functionality.

Program 4: Basic Inheritance

class Person {
    String name;
    int age;

    Person(String name, int age) {
        this.name = name;
        this.age = age;
    }

    void displayPerson() {
        System.out.println("Name: " + name);
        System.out.println("Age: " + age);
    }
}

class Student extends Person {
    int rollNo;
    String branch;

    Student(String name, int age, int rollNo, String branch) {
        super(name, age);
        this.rollNo = rollNo;
        this.branch = branch;
    }

    void displayStudent() {
        displayPerson();
        System.out.println("Roll Number: " + rollNo);
        System.out.println("Branch: " + branch);
    }

    public static void main(String[] args) {
        Student s = new Student("Sneha", 19, 327, "Information Technology");

        System.out.println("Student Details");
        System.out.println("----------------");
        s.displayStudent();
    }
}

Sample Output:

Student Details
----------------
Name: Sneha
Age: 19
Roll Number: 327
Branch: Information Technology

Experiment 5: Using super Keyword

Problem Statement: Write a Java program to demonstrate the use of the super keyword for accessing superclass variables, methods, and constructors.

Program 5: Using super Keyword

class Employee {
    String name;
    double salary;

    Employee(String name, double salary) {
        this.name = name;
        this.salary = salary;
    }

    void displayDetails() {
        System.out.println("Employee Name: " + name);
        System.out.println("Salary: " + salary);
    }
}

class Manager extends Employee {
    String department;

    Manager(String name, double salary, String department) {
        super(name, salary);
        this.department = department;
    }

    void displayDetails() {
        System.out.println("Manager Details");
        System.out.println("----------------");

        // Access superclass variable
        System.out.println("Name using super: " + super.name);

        // Invoke superclass method
        super.displayDetails();

        System.out.println("Department: " + department);
    }

    public static void main(String[] args) {
        Manager m = new Manager("Arjun", 68500.50, "Finance");

        m.displayDetails();
    }
}

Sample Output:

Manager Details
----------------
Name using super: Arjun
Employee Name: Arjun
Salary: 68500.5
Department: Finance
