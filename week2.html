Week 2 – Installation of Java

1. Installation of Oracle JDK

Step 1: Download Java JDK

Open a web browser and visit the official Oracle JDK website. Download the latest JDK for Windows.

Step 2: Install JDK

  1. Double-click the downloaded .exe file.
  2. Click Next and follow the installation wizard.
  3. Complete the installation.

Step 3: Verify Java Installation

Open Command Prompt and type:

java --version

Check the Java compiler:

javac --version

Step 4: Configure JAVA_HOME and PATH

Locate the JDK installation folder.

C:\Program Files\Java\jdk-25

Open Environment Variables using Windows + R, type sysdm.cpl, and press Enter.

  1. Select the Advanced tab.
  2. Click Environment Variables.
  3. Under System Variables, create JAVA_HOME.
  4. Add the JDK path as its value.
  5. Select Path, click Edit, and add:
%JAVA_HOME%\bin

Step 5: Verify Configuration

Open a new Command Prompt and execute:

echo %JAVA_HOME%
java --version
javac --version

2. Installation of OpenJDK

  1. Open a web browser and search for the OpenJDK website.
  2. Go to OpenJDK downloads.
  3. Download OpenJDK 21.0.11 for Windows x86 64-bit JDK.
  4. Choose the Windows x86 64-bit (.msi) installer.
  5. After installation, open Command Prompt.
  6. Check the Java version and update the installation path.
  7. Write a simple Java program and run it.
